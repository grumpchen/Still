# Still Agent 生成组件 · Luna 实施方案

基线 a8e1b9f，应用代码 a3c9af5。文中列出的新增类型、接口和界面均为设计。

## 用户体验

在组件菜单选「用 AI 创建」，或在助手明确要求「做一个组件」。两个入口进入同一份草稿。输入「把讲义变成五道复习题，答案放下面」。预览直接显示将来的卡片：标题、文件投放区、主按钮、结果区。预览旁用一句话说明「读取一份 PDF 的文字，发送给 DeepSeek，结果可存入笔记」。模型随当前设置显示。用户可以改标题和指令、换样本、试跑，再点「添加到工作区」。创建时只向模型发组件需求和可用能力。试跑使用用户主动选择的样本，保存笔记由用户另点按钮。

日常使用：拖入 → 显示文件名和读取范围 → 运行 → 卡内显示结果 → 保存。提供「选择文件」作为拖放的等价入口。编辑已有卡片时保留已保存版本，取消恢复原配置。中英文界面均使用现有本地化。

## 定义与执行

建议采用带 schemaVersion 的有限类型，初版只接受以下两种组合，控件由 Still 渲染。例子是完整的第一种定义：

~~~json
{"schemaVersion":1,"title":"讲义变复习题","input":"pdf-or-text","action":{"kind":"askAI","instruction":"根据材料出五道复习题，答案单列；引用 PDF 时标注页码。"},"output":"review-note"}
~~~

第二种组合为 input=images，action.kind=imagesToPdf，output=save-pdf。处理顺序遵循用户在缩略图列表中的排序。PDF.js 用于读取；输出 PDF 需要单独选定、固定版本并验证可离线打包的写入库。第一种完成即有可用的 AI 组件；第二种完成才对外展示本地转 PDF。后续再扩展压缩、OCR、多步条件和定时触发。

模型返回候选 JSON。用同一个纯解析函数校验生成回复、用户编辑、预设和磁盘数据，按已实现的动作目录验证输入和输出的组合。限制标题及提示词长度，复用现有文档大小及 AI 请求预算。未知版本或动作显示在单张卡上并允许重新编辑，保留其他卡片。模型只指定已注册动作，不接受脚本、可执行命令或输出绝对路径。实例 ID、提供方连接、文件授权和写入目标均由 Still 管理。

生成回复格式有误时保留需求并允许编辑或重试。用户要求暂未支持的能力时明确指出缺少哪一步。例如要求 Word 保真转换时，不能把它保存成仅支持图片的转换器而声称完成。

运行时区分待选文件、就绪、处理中、待保存和失败。每次运行固定输入与规则版本；只由当前 runId 接收结果；双击合并，切换工作区或删除卡片后不向新目标写入。AI 请求只共享预览声明的文字范围，把文档正文作为资料；显示截断页数，断网时保留输入供手动重试。持久化只保存规则和布局。保存笔记时新建文档并核对目标仍有效，成功回执后才标记已保存；输出 PDF 使用另存为，取消时仍可再次保存。

## Luna 的提交顺序和验收

1. **手写定义跑通卡片。** 新类型、解析器、渲染、加载和预设。用固定样例验证合法/损坏/旧版本数据、复制独立、重启后仅恢复规则。
2. **一条完整 AI 路径。** 外部拖入或点选一份 TXT、Markdown 或有文本的 PDF，提取范围可见，生成五题并存入指定 Notes。用模拟 transport 验证只发一次、结果和笔记相符，断网、扫描 PDF、超限、目标被删时仍能继续操作。
3. **接入自然语言创建。** 先实现组件菜单创建入口，再将 Agent 的生成提案接到相同编辑器。验证中文、英文、无效 JSON、缺少能力、取消和重复确认。草稿通过校验并点击添加后只生成一张卡。确认绑定草稿和工作区，不依赖再次猜测原始措辞。
4. **本地 PDF 卡。** 支持 PNG/JPEG，多图排序、保留比例、输出副本。用 PDF.js 回读结果核对页数、顺序和尺寸；测试断网、取消保存、同名文件。之后开放此动作给生成器。
5. **发布门槛。** Playwright 跑真实 App 状态加模拟模型，覆盖创建、试跑、保存、重载，以及 drop 不穿透；Linux 浏览器结果仅代表预览。Windows CI 跑 TypeScript、相关前端及原生测试并构建 exe；交互 Windows 单独验证 Explorer 拖入、125%/150% 缩放、保存对话框。最后用可访问的 DeepSeek 做一次短样本验收，记录模型、请求次数和实际输出。自动化默认使用模拟响应。

建议从本设计分支新建 Luna 实施分支；先交付步骤 1–3 的演示，再扩充动作。首个验收场景为“说一句话创建卡片 → 拖入自己的讲义 → 看到五道题 → 保存至指定笔记 → 重启后同一张卡可处理下一份讲义”。
