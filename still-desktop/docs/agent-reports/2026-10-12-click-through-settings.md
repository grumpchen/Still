## Done
- Added persistent General settings for passing clicks through empty areas of a transparent workspace and enabling whole-window click-through.
- Transparent-area mode shapes only Still's main HWND around visible UI controls, cards, dialogs, menus, and scrollbar gutters. Widget cards are clipped to the workspace viewport and native dimensions account for window DPI and frame offsets.
- Whole-window mode can be toggled from General Settings or with Ctrl+Alt+Shift+P; the native Windows keyboard hook can restore input while click-through is active. Turning off the setting also restores normal input.
- Existing profiles default both settings to off. The options are independent and remain saved across restarts.
