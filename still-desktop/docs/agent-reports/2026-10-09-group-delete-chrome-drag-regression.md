## Done

- Empty Groups delete immediately. Non-empty Groups opened from either the tray context menu or Edit dialog use the same removal path and offer only **Delete All** and **Cancel**. Delete All removes the collection data and linked canvas Group cards; removing only a canvas Group card still leaves its saved collection intact.
- Deleting collected Apps releases their native windows. A new Chrome release path restores the window to the desktop without `WM_CLOSE` and keeps the transient recovery marker so undo/reopen can reclaim the same Chrome window.
- Expanded native Browser and Apps panels are suspended at the start of a canvas move, before React's asynchronous drag-state presentation update. Minimized widgets retain their existing shared drag/collection path. Cancellation clears the active gesture and restores the original placement.
